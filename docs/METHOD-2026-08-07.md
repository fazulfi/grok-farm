## 1. Arsitektur

```
Playwright channel='chrome' (headed/xvfb) + WebShare proxy (split-creds)
  → accounts.x.ai/sign-up?redirect=grok-com
  → random@<domain> (CF Email Routing catch-all → Gmail)
  → OTP: Gmail IMAP via proxy CONNECT tunnel (port 993 diblokir provider)
  → Verify email (6 kotak OTP, keyboard typing)
  → Complete sign up (nama + password + Turnstile solve iframe)
  → redirect grok.com → save SSO cookies → v2_sso.txt
```

## 2. Komponen & Alasan (kenapa HARUS begini)

### 2.1 Engine — Playwright `channel='chrome'`, BUKAN Camoufox
- `channel='chrome'` = fingerprint TLS/profile Chrome real (bukan Chromium build) → lolos CF lebih baik.
- `--disable-blink-features=AutomationControlled` + `ignore_default_args=['--enable-automation']`.
- **Wajib headed** (headless=False) via `xvfb-run -a` di server tanpa display.
- Non-root user (Camoufox/Chrome broken under root).

### 2.2 Proxy — WebShare, format SPLIT-CREDS (kritikal!)
```python
# BENAR (tested OK):
kwargs["proxy"] = {"server": "http://host:port", "username": user, "password": pass}
# SALAH (ERR_INVALID_AUTH_CREDENTIALS):
kwargs["proxy"] = {"server": "http://user:pass@host:port"}
```
- **Satu proxy per akun** (round-robin) — anti-plenger & fingerprint konsisten.
- Proxy non-EU (SG/US/BR) wajib untuk Grok 4.5.

### 2.3 Email — CF Email Routing catch-all → Gmail
- Domain: `gogoligo.my.id` / `.biz.id` / `.web.id` (fresh, belum ke-flag xAI).
- CF Email Routing: zone active → enable → rule `all → forward` ke Gmail verified.
- 1 Gmail bisa dipakai semua domain (Destination Address shared across zones).
- **Scale:** 1 Gmail per domain untuk isolasi rate-limit/flag.

### 2.4 OTP IMAP — VIA PROXY CONNECT TUNNEL (kritikal!)
- **idcloudhost SG blokir egress port 993** langsung (`Network is unreachable`).
- Solusi: HTTP CONNECT tunnel melalui proxy WebShare → `imap.gmail.com:993`.
- Implementasi: raw socket → CONNECT → TLS wrap → `imaplib.IMAP4` subclass (`_create_socket` return socket).
- `since_ts` = hanya proses email yang masuk SETELAH run start → **hindari OTP re-used/invalid**.
- Scan ulang semua pesan tiap iterasi (jangan `seen` sebelum match — race email datang belakangan).

### 2.5 OTP input — KEYBOARD TYPING, bukan `.fill()`
- x.ai Verify email = **6 kotak terpisah** (`input[maxlength="1"]`), React.
- `.fill()` gagal (kotak React bukan input biasa). **Click kotak pertama → `page.keyboard.type(otp_chars, delay=40)`** → auto-advance ke 6 kotak.
- Fallback: `input[name="code"]` (hidden controller) juga pakai keyboard.
- JANGAN ketik hyphen; hanya 6 alnum.

### 2.6 Turnstile — klik IFRAME `challenges.cloudflare.com` (kritikal!)
- Kotak "Verify you are human" ada di **iframe cross-origin** — `page.locator` TIDAK bisa lihat.
- `page.locator('input[type=checkbox]').first` → **SALAH** (klik checkbox cookie banner OneTrust, bukan Turnstile!).
- **BENAR:** iterasi `page.frames`, cari frame dgn URL mengandung `challenges.cloudflare.com`/`turnstile` → klik checkbox di frame; fallback klik body frame posisi (20,20).
- Dismiss cookie banner DULU (`#onetrust-accept-btn-handler` / Accept All).
- Baca token `input[name=cf-turnstile-response]` → submit.

## 3. Environment (`.env` / `.env.v2.example`)

```bash
GROK_IMAP_USER=...            # Gmail (penerima OTP via CF routing)
GROK_IMAP_PASS=...            # App password
GROK_EMAIL_DOMAINS=gogoligo.my.id,gogoligo.biz.id,gogoligo.web.id
GROK_PROXY_FILE=./proxies.txt # host:port:user:pass per baris
V2_PROXY_FILE=./proxies.txt
V2_PASSWORD=...               # password akun Grok yang difarm
V2_HEADLESS=false             # WAJIB false (headed/xvfb)
V2_TURNSTILE_PATCH=0          # extension patch sudah mati (Chromium #40280325 fixed)
V2_OAUTH_SCOPE="openid profile email offline_access grok-cli:access api:access conversations:read conversations:write"
V2_OAUTH_REFERRER=grok-build
```

## 5. Catatan Anti-Plenger (intel farmer 2026-08-07)

- JWT dgn `"bfs":1` / `"bot_flag_source":1` = akun ke-flag → thinking gak jalan → **buang**.
- Akun sehat: scope `... conversations:*` + referrer `grok-build`/`cli-proxy-api`.
- Semua ke-flag di 1 domain → **ganti domain** (domain baru = aman).
- Proxy rotate rutin; jangan lama di 1 IP untuk farm besar.
